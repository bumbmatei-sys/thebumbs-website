# The Bumbs — Missionary Website

Official source repository for **thebumbs.com**.

## Site map
- Home `/`
- About `/about` and `/ro/about`
- Journal (mission reports, stories and reflections) `/journal` and `/ro/journal`
- Former `/blog` and `/missions` links redirect to the Journal.
- Contact `/contact`
- Partner `/partner`

## Principles
Authentic photography and verified testimonies only. Editorial, Christ-centered design. Mobile floating navigation. Subtle text animation with reduced-motion support. No invented payment details or public deployment without approval.

## Development
Next.js App Router, TypeScript, Tailwind CSS. Configure and deploy to Cloudflare only after review.
